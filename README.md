# 序衡 · Xuheng

**制造供应链决策智能体。看清异常影响，权衡恢复方案，让制造决策有据可依。**

序衡把供应中断、设备停机和需求变化转化为可核查的订单影响与恢复方案。语言模型提取候选事实，OR-Tools 求解器处理物料与产能约束，独立验证器复核可行性；最终由人决定是否生成草稿工单。

## 本地启动

需要 Conda、Python 3.11 和 Node.js 22.13 以上。首次安装在项目根目录运行：

```powershell
conda env create --prefix ./.conda --file environment.yml
conda activate ./.conda
cd frontend/site
npm ci
```

启动网页工作台需要两个终端。第一个在项目根目录激活环境并启动分析服务：

```powershell
conda activate ./.conda
python -m xuheng.demo_api
```

第二个启动前端：

```powershell
cd frontend/site
npm run dev -- --port 3000
```

打开 <http://localhost:3000>。选择默认的“离线演练”，点击“开始分析”，随后比较方案、批准或驳回，并查看合同沙箱反馈。离线演练只处理固定案例，模型抽取采用回放；求解、验证、审批和本地 HTTP 沙箱均实际运行。

也可在项目根目录运行 `python -m streamlit run app.py`，打开 <http://127.0.0.1:8501>。演练实验室提供来源冲突、提示注入、无解需求、随机事故等案例，以及人工澄清和更细的工序图。

## 可以完成什么

- 从带原文定位的异常候选字段开始，核对物料、订单、产线和政策。
- 比较交付优先、均衡恢复、稳定优先三个目标下的计划与代价。
- 对供应、BOM、容量、时间窗等硬约束进行独立验证；无解或信息冲突时暂停。
- 把审批绑定到具体场景、计划和审批人。输入变化或执行回流改变约束后，旧审批不能复用。
- 输出草稿采购与排程动作；在本地合同沙箱中演练消息接收、部分执行、回调、幂等与重算。
- 配置后接入兼容 OpenAI 格式的真实模型、ERPNext 和 OpenMES 测试实例。

## 数据与执行范围

内置 217 台汽车需求的演练案例使用公开工作簿与明确标记的合成覆盖层，不能视为真实工厂生产记录。图片 OCR 定位采用预计算样例，PDF 与 CSV 证据保留内容哈希。详见 `data/provenance.md`。

默认不需要模型密钥。实时模型和外部系统只有配置后才启用；本地沙箱不等于商业厂商认证接入。所有凭据在服务端读取。已批准动作也只允许生成草稿，不包含设备控制、支付、生产库存过账或原生系统审批。

## 工程入口

| `src/xuheng/` | 领域模型、求解器、验证器、决策图及集成适配器 |

| `app.py` | Streamlit 演练实验室 |
| `data/` | 公开数据、合成案例、政策、模型回放与证据 |
| `contracts/` | OpenAPI、AsyncAPI、自有消息模式与映射 |
| `scripts/`、`tests/` | 数据生成、验证工具及自动化测试 |
